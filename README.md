# Tu barbería

Tarjeta de sellos para clientes de una barbería.

- `index.html`: página web (se publica con GitHub Pages).
  - Barbero: `/?barbero`
  - Cliente: `/?c=CODIGO`
- `firestore.rules`: reglas de seguridad para pegar en la consola de Firebase.
- `app-movil/`: versión de app móvil con Expo (opcional).

Antes de usar, completa `firebaseConfig` y `SHOP` en `index.html`.
